# 🌸 二周目花月 - AstrBot 插件

末世生存文字RPG游戏插件。

## 功能特性

- 🎭 **阵营系统** - 4个可选阵营，各有不同属性加成
- ⚔️ **六维属性** - 力量、敏捷、体质、智力、感知、运气
- 🗺️ **走格子探索** - 8x8 随机地图，可视化显示
- ✨ **随机支线剧情** - 每次探索最多触发2个支线
- 🏆 **成就系统** - 完成支线解锁对应成就
- 💾 **数据持久化** - 自动保存玩家进度

## 安装

在 AstrBot 插件市场搜索：`astrbot_plugin_erzhoumu`，或手动上传安装。

## 使用指令

默认指令前缀为 `花月`。

| 指令 | 说明 | 示例 |
|------|------|------|
| `注册 [阵营]` | 注册新玩家 | `/花月 注册` |
| `阵营` | 查看所有可选阵营 | `/花月 阵营` |
| `属性 力 敏 体 智 感 运` | 分配六维属性 | `/花月 属性 10 10 5 5 5 5` |
| `状态` | 查看你的角色状态 | `/花月 状态` |
| `探索` | 开始一次探索（消耗10体力） | `/花月 探索` |
| `移动 方向` | 在地图上移动 | `/花月 移动 右` |
| `背包` | 查看背包物品 | `/花月 背包` |
| `成就` | 查看已获得的成就 | `/花月 成就` |
| `帮助` | 显示帮助信息 | `/花月 帮助` |
